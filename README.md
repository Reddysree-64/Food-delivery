# 🍔 Foodie – Food Delivery Website

I'm excited to share **Foodie**, a food delivery website that I built as part of my learning journey in web development.

The idea behind this project was to create a simple and attractive website where users can explore food items, add their favourites to a cart, and manage their orders.

## ✨ Features

- User Sign Up and Login
- Attractive food menu with food images and prices
- Add to Cart functionality
- Order placement and order management
- Edit and delete orders
- Customizable colour themes with 8 options
- Light Mode and Dark Mode
- Theme preferences saved using Local Storage
- Responsive and attractive user interface

## 🛠️ Technologies Used

- HTML – Website structure
- CSS – Styling, layouts and animations
- JavaScript – Functionality and interactivity
- Browser Local Storage – Saving user and order information

## 🎨 Available Themes

1. Royal Orange
2. Black & Gold
3. Fresh Green
4. Ocean Blue
5. Cherry Red
6. Rose Pink
7. Coffee Brown
8. Teal Elegance

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Sign up and explore the website.

## 📚 What I Learned

While building this project, I got practical experience with HTML, CSS and JavaScript. I learned how to work with buttons, forms, Local Storage, dynamic content, and user interactions.

This project helped me understand how different parts of a website work together.
